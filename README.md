# 侯同学呀 · Signal Atelier / V18

这是一个原创的静态个人网站，可部署到 GitHub Pages。视觉参考是精致的材质、光影和空间层次，而非复刻其他网站的场景或版式。

## 发布
将 `index.html`、`assets/v18.css`、`assets/v18.js` 上传到原仓库同名路径，其他项目详情页保留即可；GitHub Pages 使用 `main / (root)`。

## 内容说明
- 字体：站酷庆科黄油体、Anton，正文 Noto Sans SC，Google Fonts 在线加载（断网自动回退）。没有从参考网站拷贝字体文件。
- 首页项目视觉是独立绘制的网页示意，不是产品真实截图。
- 案例链接跳转现有 `projects/*.html` 页面。
- 联系方式目前指向之前使用的公开 X 账号，请核实是否有效。
- 未接入表单、后台或访客跟踪；没有虚构案例收益、粉丝量和品牌合作。

## 验收
检查电脑和手机排版、项目链接、滚动、合作话题复制及控制台错误。

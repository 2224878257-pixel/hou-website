# 侯同学呀 · Personal Field Notes V8

基于 V7 的渐进式升级，保留原创首页与文件夹滚动叠放，新增 **5 个可独立访问的项目档案页**。

## 文件结构
- `index.html`：网站首页
- `assets/styles.css`：原有设计与 V8 案例页样式
- `assets/main.js`：首页交互及案例入口
- `projects/*.html`：5 个独立案例页

## GitHub Pages 更新方式
仓库 `2224878257-pixel/hou-website` 使用 **Deploy from a branch → main → /(root)**。
上传本更新包中的三个已有文件，并新建 `projects/` 文件夹上传其中五份 HTML。无需调整 Pages 设置或使用 GitHub Actions 工作流。

## 重要说明
案例封面为设计插画，不是产品截图；未填写未经确认的外部项目链接，也未虚构数据或已实现功能。
联系明信片只复制文本，不会发送邮件。留言墙只保存在访客本机。下一轮可以在确认真实对外邮箱、项目演示 URL 后替换。

## 验收清单
- 打开首页并向下滚动，5 张文件夹逐张 sticky 叠放
- 每张文件夹点击「查看完整案例」能打开对应档案
- 项目弹窗的「查看完整档案」链接能跳到对应页面
- 档案页支持返回首页和前后案例切换
- 手机宽度 390px 不应横向溢出
- 明信片复制后明确提示需要自行发送

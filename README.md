# 侯同学呀 · 互联网信号局 (V20)

原创个人网站，风格方向：研究者的数字信号档案。保留 ZCOOL QingKe HuangYou 和 Anton 标题字体。

## 使用方式

纯 HTML / CSS / JavaScript，无构建工具，无 API，无数据库。可以将本目录全部文件上传到 GitHub Pages 仓库根目录，Pages 配置选择 `main / (root)`。如浏览器限制 `file://`，在该目录运行 `python -m http.server 8000`，然后访问 http://localhost:8000。

## 更新内容

- `index.html`：首页介绍、项目列表、联系方式。
- `assets/site.css`：整体视觉。
- `assets/main.js`：交互信号信息和移动导航。
- `projects/*.html`：六份独立项目说明。
- `lab.html`、`research.html`、`writing.html`：分类索引。

## 上线前提醒

1. 真实项目网址和截图尚待补充；页面没有虚构粉丝量、客户品牌或实际经营收益。
2. 联系按钮暂时打开 GitHub 主页，未接入商务邮箱和发送表单。
3. Google Fonts 在部分地区可能加载失败，系统字体作为回退。允许自托管时可后续接入授权字体文件，但本压缩包不附带字体文件。
4. 手机需测试 Safari/Chrome 真机；已做桌面和手机自动截图检查。
5. 暂不使用追踪服务和第三方分析脚本。
